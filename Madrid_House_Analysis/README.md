📊 Project Summary  
Built an interactive real estate analytics dashboard to analyze housing prices in Madrid, identify neighborhood-wise trends, property characteristics, and investment opportunities.

🔍 Key Insights  
Identified high-price and low-price neighborhoods  
Analyzed price trends across property sizes and room counts  
Compared districts by average price per square meter  
KPI tracking for market monitoring and investment decisions
